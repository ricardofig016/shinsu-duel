# Contracts

New mechanic added to the game.

## Rules

on game start, before even initial hand is drawn: show 3 random contracts to both players.

each player selects a contract to refuse: the one that they DONT want to be applied.

after both players select their refusal:
- chose different: the remaining third one is selected
- chose the same: select randomly one of the remaining two

## Examples

### Wall

lighthouses have Resilient

### Enriched Shinsu

all skills cost 1 less

### Shinsu Masters

wave controller abilities activate twice

### Order

sort decks from cheap to expensive

### Pool

start with 4 shinsu slots instead of 1

### Boss

the first unit in both decks has 99hp

### Ruin

destroy all landmarks from decks

### Darkness

if you dont have a lightbearer, all allies have Blinded

### Sabotage

numeric conditions given to enemeis by scouts are doubled

### Team Leader

fishermen gain 3 random traits on summon

### Shooting Range

players have 2 spear bearer combat slots
